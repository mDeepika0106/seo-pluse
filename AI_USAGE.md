
# AI Usage Documentation

## AI Tools Used
- ChatGPT
- Groq API

## AI Assistance During Development
ChatGPT was used as a development assistant to help understand project requirements, plan the application structure, develop code, debug errors, and understand testing.

AI assistance included:
- Understanding the assignment requirements.
- Planning the Python project structure.
- Explaining web crawling logic.
- Implementing SEO metric extraction.
- Developing URL validation and redirect safety logic.
- Creating the scoring system.
- Writing automated tests.
- Debugging implementation issues.
- Preparing documentation.

## AI Usage Within the Application
The Groq API is integrated into the application to generate SEO recommendations based on the audit results.

The AI:
- Analyzes the audit findings.
- Prioritizes SEO issues.
- Suggests improvements.
- Provides actionable recommendations.

The AI does not crawl websites, extract metrics, or calculate the SEO score. These tasks are performed by the Python application.

## Human Verification
The code, test results, audit outputs, and recommendations were reviewed and tested during development. Automated tests were used to validate important functions.

## Limitations
AI recommendations may occasionally be inaccurate or incomplete. Users should verify recommendations before implementing them.
